# trassa-agent

Открытый агент [Trassa](https://github.com/NogMeer/Trassa) для серверов клиента. Лицензия Apache-2.0.

Агент сам открывает исходящее соединение WSS на 443 к управляющему сервису, принимает только подписанные типизированные операции из фиксированного каталога и не открывает входящих портов. Протокол и модель безопасности описаны в `proto/` и в плане Trassa (`docs/plan/04-agent-protocol.md`, `03-security.md`).

## Состав

- `proto/trassa/agent/v1/` — контракт канала «агент ↔ шлюз» (protobuf). Сообщения добавляются в E05.
- Код агента на Go (два процесса: `trassa-agent` без прав и `trassa-helper` под root) — E05.
